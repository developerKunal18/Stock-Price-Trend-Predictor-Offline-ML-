# 💹 Stock Price Trend Predictor

## 💡 Overview
The **Stock Price Trend Predictor** is an offline Python application that uses **machine learning** to predict the next day’s stock price trend.

It trains a **Linear Regression model** on historical stock data and forecasts whether the price is expected to go **UP 📈 or DOWN 📉**.

This project demonstrates how financial prediction systems work in real-world trading and analytics platforms.

---

## 🚀 Features

### 📈 Price Prediction
- Predicts tomorrow’s stock price based on past data

### 🧠 Machine Learning
- Uses **Linear Regression**
- Trains on historical price trends

### 🔮 Trend Detection
- Automatically identifies whether the stock is going **up or down**

### 🌐 Fully Offline
- No APIs
- No live stock data required
- Works entirely on local data
